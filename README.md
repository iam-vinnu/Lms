# 🌳 SkillTree

**SkillTree** is a modern Learning Management System (LMS) web application built with the **MERN** stack. Designed to empower learners and educators, SkillTree offers seamless course management and a robust progress tracking system.

---

## 🚀 Features

- 📚 **Course Management**: Create, update, and organize courses with ease.
- 📈 **Progress Tracking**: Monitor learner activity and visualize progress over time.
- 👥 **User Roles**: Separate views and access for admins, instructors, and students.
- 🔐 **Authentication**: Secure login and registration for users.
- 🎯 **Interactive Learning**: Rich course content with videos, quizzes, and assessments *(coming soon)*.

---

## 🛠 Tech Stack

**Frontend**
- React.js
- Redux/RTK query
- Tailwind CSS 

**Backend**
- Node.js
- Express.js
- MongoDB (with Mongoose)

**Authentication**
- JWT-based authentication
- bcrypt for password hashing

---

## 📦 Installation

```bash
# Clone the repo
git clone https://github.com/iam-vinnu/skilltree.git

# Install backend dependencies
cd server
npm install

# Install frontend dependencies
cd ../client
npm install
```

---

## 🧪 Usage

```bash
# Start backend server
cd server
npm run dev

# Start frontend
cd ../client
npm start

```
